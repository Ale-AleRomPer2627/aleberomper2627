Nuestro Equipo de Desarrollo

Somos un equipo de estudiantes de Desarrollo de Aplicaciones Web (DAW) aplicando metodologías de control de versiones con Git y flujos de trabajo profesionales (GitFlow)[cite: 1, 4].

Este proyecto simula un entorno laboral real donde dividimos las tareas entre el Jefe de Proyecto y los desarrolladores para integrar nuevas funcionalidades mediante ramas y Pull Requests.
